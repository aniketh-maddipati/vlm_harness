# Skim faults: nothing the user did is ever lost, nothing hangs (branch video/skim-faults)

Goal: every failure is survived, said in plain words, and recoverable; marks are never lost. Mostly a test harness
plus the fixes it forces. Owner of: the fault fixtures, Tests/web/skim-faults.*, and small fixes in the page's error
paths (readClip catch/why, runPass halt/retry, save/persist, closeShoot). Not the grid drawing, grouping, Rec.709,
or ingest speed (other worktrees). Merge video/skim-mvp before page edits; keep page copies byte-equal.

## Faults to inject (each: a fixture or a scripted condition, the expected behaviour, a test)
Files: 0-byte clip; truncated clip (cut at 10/50/90%); corrupt header; clip with no video track; audio-only; a
codec this browser can't play (10-bit H.264 in Chromium); a sidecar that doesn't match its clip; a sidecar with no
clip; duplicate names in two folders; very long names / unicode; 4,000 tiny clips; one 4 GB clip; clips with no
metadata at the end; a ProRes .mov; files that are not video in the folder (.DS_Store, ._ AppleDouble, .XML, .JPG).
Conditions: the card or drive goes away mid-read (files start failing); the tab hidden mid-read; the page reloaded
mid-read; the Mac sleeps; storage quota full (localStorage / IndexedDB writes throw); memory limit hit while
reading; a second shoot opened mid-read; Make frames again / Close / test load while reading; very slow reads
(throttled); Escape and ⌘W during every state; undo after reload.

## Must hold
- Marks: written on every change (and on pagehide/visibilitychange), restored by clip identity after a reload,
  a crash, or reopening some/all clips; never written to the clip files; a full quota says so and keeps marks in
  memory (and offers Export) instead of failing silently.
- Reading: no read waits forever (every await has a timeout); failures are classified (can't play / damaged /
  cut short / too slow / card gone / tab hidden) and shown per clip; three "card gone" in a row stops with Go on;
  retry is bounded; a reload resumes where it was (with ingest's cache, instantly).
- UI: never a frozen screen (> 100 ms main-thread task while reading is a bug); every error message says what to do.
- Export: always produces a valid file from whatever is marked, even with failed clips (skipped and listed).
Deliver: the fixture set (small, generated by a script, gitignored if large), the tests (CI-able on Chromium with VP9
fixtures; a WebKit run on the Mac), a table fault → behaviour → pass/fail, and the fixes.

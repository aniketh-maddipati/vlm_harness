How this file was made (2026-10-01)
  - Each shipped file is byte-identical to design/handoff/vendor/ and matches the
    SRI hash pinned in the design's support.js (see design/handoff/vendor/VENDOR.md).

    exact version on npm (fetched from unpkg.com, URL given with each entry),
    unless the entry says otherwise. Nothing here was written from memory.
  - Banners: the licence comments still present inside the shipped files are

    React's own banner and a one-line Modernizr fragment banner (Part 2).
  - @babel/standalone: the shipped babel.min.js keeps only ONE embedded licence

    list of packages bundled inside it (Part 4) therefore does not come from the
    shipped file but from the source map Babel publishes for this exact build
    (https://unpkg.com/@babel/standalone@7.29.0/babel.min.js.map, 1008 sources).

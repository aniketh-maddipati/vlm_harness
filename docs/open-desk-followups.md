# Open desk — what is left, and what to study

Notes for a later pass. This stays on `codex/open-desk-tiles`. Do not fold it into the phone-classification branch.

The desk already ranks shoots into Continue, larger sets, and a short quieter row. Harness-named folders stay off it. Each tile shows a spread of frames, where the work stands (as you left it, N kept, still open, none kept), the photograph count, and the date as a caption. The press is a veil. A resting pointer does not change the plate.

## What the tile is for

Ranked. Date is a caption, not the identity.

1. The frames. That is how you know which shoot it is.
2. Where the work stands. Left open, kept, or not yet marked.
3. How many photographs. The numeral, and why a plate is large or quiet.
4. When. Separates two shoots that look alike. Becomes the title only when the folder name is not a name.
5. The folder name, when it is a real one.

Three axes: recognition (frames), progress (left open versus kept), scale (the count). File size, a percent bar, and a color for freshness do not belong on the tile.

## Patterns other apps already use

These products do not draw every object the person ever touched. Decay hits the score, or the tab, not the file.

| Product | What earns the front | What stays off it |
|---|---|---|
| Firefox | Frecency: visits times a daily decay, about a 28-day half-life | The page itself. Age lowers rank. It does not delete history. |
| Slack | The person you actually open, from the last few uses plus a long-run count | The other person with the same name. Search still finds them. |
| VS Code | A short recent menu, and on the Mac dock about seven workspaces that still exist | Missing paths, junk filenames, and the long tail behind More. |
| Arc | Pinned tabs, then today. Unpinned tabs archive on a daily sweep | Yesterday’s unpinned tabs. Archive is a drawer, not a deletion. |
| Linear | Work in motion. Completed projects collapse. Supporting chrome recedes | A flat list of every project at the same size. |
| Photo Mechanic | Ingest is a contact sheet of the card. Names come from capture time before anything is copied | A path chooser as the product. |
| Image Capture | Thumbnails of the card first, then which frames | A blind copy of the whole volume. |
| Capture One | The folder is the session. The browser is the photographs | The folder name as the only way to know what is inside. |

Sources worth rereading: Firefox Places frecency, Slack’s Quick Switcher note, VS Code `workspacesHistoryMainService` (dock cap, existence check), Arc’s archive, Linear’s note that not every element should carry equal weight.

## What a working photographer needs from this surface

- To recognize a shoot when the folder is `100MSDCF`, `Untitled`, or a generated suffix. The pictures do that. The date helps only when two sets look alike.
- To see whether the cull has started. “Still open” and “N kept” answer that. A finished-set badge is the same fact, not a new one.
- One thing to resume, then the sets that are actually large. A test folder and a wedding should not be the same plate.
- The way in (Open a folder, or a drop) stays reachable. It should not be the last cell of a growing grid.
- Nothing they marked is thrown away because it got old. An unopened shoot can leave the desk. It stays on disk until they remove it.
- The block should feel settled: press answers, the photograph does not fade or stretch, and the pointer does not invent a second state.

## What not to copy

- Bubble maps and heat maps. They make every project a peer and fight the plates.
- A time-to-live that deletes a shoot someone opened.
- Equal tiles for every folder that exists.
- Hover that reveals the real preview. The frames are the tile, at rest.

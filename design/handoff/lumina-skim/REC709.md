# Skim Rec.709: is the S-Log3 preview accurate (branch video/skim-rec709)

Scope: Rec.709 only (no creative colour, no masking). Owner of Component.SL3T / SL3M / toDisplay / sl3Table /
calibrate and the preview filter. Merge video/skim-mvp before page edits; keep page copies byte-equal.

## Mandatory transform chain (each step must be right; record each)
1. Decode HEVC Main 10 4:2:0 (friend's XAVC HS) → YUV 10-bit, video levels 64–940.
2. YUV → RGB with BT.709 coefficients (file says CodingEquations rec709) and range expansion.
3. S-Log3 → linear (Sony's published curve).
4. S-Gamut3.Cine → Rec.709 primaries (3×3, linear).
5. Tone map (~15 stops into Rec.709) — the only choice; defined by the reference below.
6. Rec.709 OETF; browser/WebKit colour management to the display.
Also: what WebKit/Chromium do to BT.709-tagged/untagged video before the page sees it (calibrate()).

## References (in order of what the friend trusts)
A. Final Cut Pro's own conversion: import T7/friend_test_log/C4815.MP4 (and the other four) into a scratch library on
   the internal disk, Leave files in place; check Info ▸ Camera LUT / log processing says Sony S-Log3/S-Gamut3.Cine;
   Save Current Frame at fixed timecodes (00:00:02:00, 00:00:05:00, 00:00:08:00) as 16-bit TIFF/PNG; note FCP
   version and the exact LUT name. Uses computer use on Final Cut Pro (the user granted it); never touch his libraries,
   never delete anything, read the T7 only.
B. Sony's official S-Log3/S-Gamut3.Cine → 709 cube (if the user puts it on the T7).

## Method
Same frames through Lumina's chain (ffmpeg extract with in_color_matrix=bt709:in_range=tv, then the page's table and
matrix in Python), and through the page in Safari (screenshot of the canvas pixels via the debug hook) — compare to A
(and B) per pixel: ΔE2000 mean/95th, plus a side-by-side image. Target mean ΔE < 2. If step 5 differs, refit SL3T
to the reference; re-run; check the measures (dark/bright/clipped/crushed) move with it.

## Deliver
Numbers per clip and step, the side-by-sides, the refit (if any) committed, and a one-line verdict the user can say
to the friend ("matches Final Cut's Sony conversion within ΔE x").

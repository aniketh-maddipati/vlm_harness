## House style

Every numbered entry uses four fields:

- **decision** — what ships
- **why** — the load-bearing reason
- **rejected** — the alternatives that lose
- **history / socket** — provenance, shelved doors, or future sockets

Citations use `L1`…`L5` (Five Laws), `D#` (contract entries), `R-*` (ruling ids).

## Five Laws (immutable — carried)

These are not reopened by v6.

**L1 — Touch moves, never decides.**  
Pointer, drag, and keyboard travel change focus, selection, and staging only; only decision keys commit.

**L2 — Hold Space, release returns.**  
Transient loupe / Before states revert on release; force-press is optional redundancy, never the only route.

**L3 — The table keeps working.**  
Failures wear a facts-chip; one sentence names it; one action fixes it; never a modal dead-end.

**L4 — Nothing the user did is ever lost.**  
Continuously saved; quit-anywhere restores the exact table; un-applied staging cancels like Esc.

**L5 — Esc restores space.**  
Esc narrows one scope ring or cancels staging; at the row ring Esc cancels the whole stage; drag origin gaps stay visible until resolved.

## Amended entries (cited D-numbers — prior text unverified)

### D24 — Value-echo during adjustment only *(amended by R-X.1 + audit)*

- **decision:** Value-echo on adjusters appears **during adjustment only**. At rest, settled changed values remain on the rail as the edit summary (dark value); no hover path reveals, amplifies, or explains a value. Touches R-X.1 (hover deleted) and R-5.2 (clipping is hold grammar, not hover).
- **why:** Information must be at-rest or during-action (R-X.1). Hover-only value affordances violate that; during-adjustment echo is the sanctioned transient.
- **rejected:** Hover-to-reveal values; persistent “live readouts” that compete with the photograph; any echo that invents a reason (“because…”).
- **history / socket:** Amends prior D24 (text absent this workspace — CONFLICT). Control anatomy hi-fi: ADJUSTING = value echoes at the pointer; SETTLED, CHANGED = dark value on the rail. Citations: R-X.1, L1, WG-chrome.

### D27 — Birth opacity only *(amended by audit frame-F — one-line)*

- **decision:** Photograph opacity animates **only at birth** on the table; after birth, photographs do not run opacity transitions (they travel and sharpen; chrome may fade).
- **why:** Photographs never fade as chrome does (WG-photos). Post-birth opacity reads as the photograph disappearing — a trust break.
- **rejected:** Post-birth photograph opacity fades; blur-storm landings under Reduce Motion exemptions that still opacity-pulse photos after birth.
- **history / socket:** Explicit one-line audit amendment to D27 (prior text absent — CONFLICT). Aligns fill-up motion note: “opacity here exists only at birth.” Citations: audit frame-F, WG-photos, L3.

### D36 — Rejects endgame / ONE file-touching verb *(amended by R-M.1 — verbatim intent)*

- **decision:** After a successful export receipt (`✓`), the post-export surface may offer **`Rejects to Trash · N files · size`**. That offer is the **ONE** file-touching verb in the product. It moves rejects to **macOS Trash only**. It is **never automatic**, **never before ✓**, and **never asks twice**.
- **why:** Destructive file motion must sit after a completed keep-path proof (export ✓) and must be a single, reversible-via-Trash act — L3/L4 shaped as one sentence + one action.
- **rejected:** Auto-trash on cull; trash-before-export; second confirm sheets; moving files anywhere other than Trash; per-network “cleanup”; any second file-touching verb.
- **history / socket:** R-M.1 — amend D36 verbatim (prior D36 text absent — CONFLICT). Copy lands in the frozen copy table. Citations: R-M.1, L3, L4, D61 (Export three-state).

## New contract entries (rulings integrated)

### D41 — Chip copy in consequence language *(R-5.1)*

- **decision:** User-visible chips that speak about fidelity or readiness use **consequence language** of the “sharpness not final” class — they state what is true of the current rung’s consequence, never a diagnosis essay and never a “because.”
- **why:** Chips are facts (Prompt Pack). Consequence language keeps the chip honest about what the user can and cannot conclude at this rung.
- **rejected:** Explanatory chips; scoring chips; “AI thinks…”; any chip containing “because.”
- **history / socket:** R-5.1. Touches WG-fidelity, R-5.3 (no positive chip invented at settle), L3. Exact additional chip strings beyond the frozen table are OPEN if not named by ruling or copy table.

### D42 — Clipping joins the hold grammar *(R-5.2)*

- **decision:** Clipping visualization is a **held-key / held-control** glance, available anytime under that hold grammar. The prior “only while a tone control moves” trigger becomes a **subset** of the hold grammar, not the ceiling.
- **why:** Clipping is a transient truth signal like loupe (L2 family): present while held/engaged, gone on release — not a mode and not hover.
- **rejected:** Persistent clipping overlay; hover-to-show clipping; modal clipping tools; release-commit of clipping state.
- **history / socket:** R-5.2. Supersedes hi-fi frame chip wording that limited clipping to tone-control motion alone. Touches L2, R-X.1, D24.

### D43 — Settle-as-confirmation *(R-5.3)*

- **decision:** The **final rung crossfade** is the one sanctioned **positive** truth signal that the image has settled. **No chip is invented** to congratulate settle or announce “full truth.”
- **why:** Absence at full truth is already the fidelity contract (WG-fidelity). A positive settle chip would invent chrome the photograph does not need.
- **rejected:** “1:1 · full RAW” chips; toast/checkmark celebrations; any second positive truth channel beside the crossfade.
- **history / socket:** R-5.3. Touches WG-fidelity, D41, L2 (hold glances remain separate). Motion token: warm-in / fidelity crossfade 120 ms where cited (see also D58).

### D44 — ⌥⌘E recipe re-entry *(R-8.1)*

- **decision:** `⌥⌘E` reopens Export with the recipe pre-filled (including last export folder path when known). Copy: frozen `⌥⌘E changes the recipe.`
- **why:** Recipe change is a deliberate re-entry, not a settings safari. One chord, one surface.
- **rejected:** Separate “presets” surfaces; copy-settings flows; inventing a second export preferences window with banned words.
- **history / socket:** R-8.1. Touches D62, copy table EXPORT, banned-words line. Engineering: `IngestPreferences.lastExportFolderPath` remains the path socket.

### D45 — Diagnostics local-only or absent *(R-9.1)*

- **decision:** Diagnostics are **local-only or absent**. Reveal and send are **manual only** — never automatic egress, never silent upload.
- **why:** “nothing leaves this Mac” is Open-surface law; diagnostics must not become a stealth network channel (zero egress / no network entitlement ideal).
- **rejected:** Auto crash reporters; background telemetry; implied consent banners that send on click-through; network calls from failure chips.
- **history / socket:** R-9.1. Touches L3, Open sovereignty line, banned network pattern. Socket: manual reveal/send UI — not designed in this session (OPEN if chrome is required).

### D46 — Amateur pivot + Develop gate *(R-A.1)*

- **decision:** Story re-weights to **land → tidy → Tier 0 → cull → export**, with **propagation as act two**. **Tier 1 + A-ladder** under the **Develop** rename is the critical path for tasteful finishing, **GATED on taste-model proof**. Until that gate passes, Develop remains **banked in the Shelved Register** (door, not deletion). Success test rewrites to: **finished, happy, organized — having read nothing.**
- **why:** The product must land amateurs who never open a manual; Develop is the sanctioned physical word (key stays `A`) but must not ship as critical path before taste proof.
- **rejected:** Shipping Tier-1 / A-ladder as ungated critical path; renaming Develop to any banned synonym (Auto/AI/smart); making propagation act one; success metrics that require reading chrome.
- **history / socket:** R-A.1 + audit (“Develop banked in the shelved register”). Touches Shelved Register, decision key `A`, R-A.2, quarantine (no TasteIndex/PhotoScorer route). Gate artifact: taste-model proof — not defined here (OPEN: proof protocol).

### D47 — Pointer path to culling *(R-A.2)*

- **decision:** A pointer path to culling is **shelved at MVP-question rank**. Any future design must survive **nothing hover-only** (R-X.1) and **chips-are-facts** (no “because”).
- **why:** Amateurs may need a non-keyboard door; it must not reintroduce hover grammar or persuasive chips.
- **rejected:** Hover-only mark affordances; click-commit without a decision key equivalent that still obeys L1; badge chips that explain why to reject.
- **history / socket:** R-A.2 — shelf entry, not implementation. Touches L1, R-X.1, D41, Shelved Register.

### D48 — Hover deleted entirely *(R-X.1)*

- **decision:** **Hover is deleted entirely.** All information is **at-rest** or **during-action**. No hover handlers. Audit D24 value-echo as during-adjustment only (see D24).
- **why:** Hover-only affordances fail keyboard, fail trackpad certainty, and invent a secret layer of UI.
- **rejected:** Hover keycaps on photographs; hover-only footers as the sole teacher; CSS/SwiftUI hover handlers for product information; timed hover (≥500 ms) hints as a required path.
- **history / socket:** R-X.1. Supersedes hi-fi frame notes that taught “hover ≥500 ms = the key hints.” Copy table removes “(hover)” parentheticals. Touches L1, L2, D24, D42, D47.

### D49 — Layout quantized everywhere *(R-X.2)*

- **decision:** Layout is **quantized everywhere**. Nothing interpolates at rest. Fixed window minimum is implied by the **800 pt rail** (shipped min window **1280×800**). Pinch density **snaps between named steps**.
- **why:** Interpolated rest layout reads as unfinished and breaks target constancy; named density steps keep the table measurable.
- **rejected:** Continuous pinch scaling at rest; fluid window layouts that shrink decision targets; interpolating gap vocabulary.
- **history / socket:** R-X.2. Touches WG-chrome, WG-gaps, elasticity quantized steps (hi-fi long-burst). Named density step list beyond existing P0 densities — OPEN if not already named in tokens.

### D50 — Distribution: Developer ID direct *(R-I.1)*

- **decision:** Distribution is **Developer ID direct**. Mac App Store is **deferred with socket**.
- **why:** Direct distribution matches offline licensing (D52) and avoids store constraints during grammar stabilization.
- **rejected:** MAS-first; unsigned distribution as the plan.
- **history / socket:** R-I.1 — MAS socket only. Touches D51, D52.

### D51 — Silent updates *(R-I.2)*

- **decision:** Updates download in the **background**, **apply on quit**, surface at most a **footer fact**, and support **rollback until first clean launch**. The **grammar-stability suite** is the pre-release gate that makes silent apply honest.
- **why:** Update UX must not invent modes or modals; honesty requires the grammar suite before silence is allowed.
- **rejected:** Forced mid-session relaunch modals; auto-apply while staging exists without quit; update progress bars as product chrome; silent apply without grammar-stability gate.
- **history / socket:** R-I.2. Touches L3, L4, D45 (no network entitlement creep beyond update channel — OPEN: update channel vs zero-egress ideal).

### D52 — Offline licensing *(R-I.3)*

- **decision:** Licensing is **offline**, **no account**, at most **one cached activation**. Trial failure fails like everything fails: **one sentence, one action, nothing lost** (L3/L4).
- **why:** Sovereignty and quit-anywhere restore forbid account gates and modal dead-ends.
- **rejected:** Account-required licensing; online heartbeat as hard dependency; trial walls that discard table state; multiple cached activations as a feature.
- **history / socket:** R-I.3. Touches L3, L4, D45, Open “nothing leaves this Mac.”

### D53 — Device-plug ingestion *(R-M.2)*

- **decision:** Device-plug ingestion is in-contract. **iPhone ProRAW** and **HEIC** are **first-class bodies** alongside camera-card RAW.
- **why:** Phone bodies are real shoots; treating them as second-class invents a false import caste (and “import” as noun stays banned).
- **rejected:** Phone-as-JPEG-only; forcing a conversion sidecar UX; separate “phone mode.”
- **history / socket:** R-M.2. Touches fixture manifest, L3 (offline/damaged chips), WG-quarantine (ExifToolService salvage).

### D54 — Bundled sample shoot onboarding *(R-M.3)*

- **decision:** Onboarding is a **bundled sample shoot**. Copy fact: **`Sample shoot — yours replaces it`**. It **retires silently** on first real ingest.
- **why:** Tour-less first run (hi-fi: two facts, no tour) needs real photographs, not empty chrome.
- **rejected:** Multi-step tours; persistent sample after real ingest; sample that overwrites user work.
- **history / socket:** R-M.3. Touches L4, fixture manifest sample-shoot spec, Open first-run frames.

### D55 — Share sheet as recipe destination *(R-M.4)*

- **why:** One recipe keeps Export honest; per-network presets reintroduce banned “preset” grammar.
- **rejected:** Instagram/TikTok/etc. preset packs; copy-settings between networks; second recipe store.
- **history / socket:** R-M.4. Touches D44, D62, banned-words line. Exact destination field labels — OPEN if not in frozen copy.

### D56 — Videos copied, counted, not shown *(R-M.5)*

- **decision:** Videos are **copied** and **counted**, **not shown** on the table. **✓ covers them** in the copy/safe-to-eject sense.
- **why:** The table is for photographs; videos must not vanish from the card silently nor invent a video editor.
- **rejected:** Video frames on the table; auto-transcode; separate video mode; leaving videos uncopied without a fact.
- **history / socket:** R-M.5. Touches L3, card copy grammar, fixture `mixed-video`. Count surfacing copy — OPEN if a chip is required beyond existing copy facts.

### D57 — 90 px halo / PERSUADE *(R-Q.1)*

- **decision:**
  - **PERSUADE** is the target for adapted-preview legibility at strip scale.
  - Adapted previews render from the **proxy-linear rung** (never embedded JPEG).
  - **Warm-in** is a **120 ms crossfade** so change itself is visible.
  - Near row-mates may sit at **120–140 px** within existing elasticity.
  - **Fallback A** (brighter ring) is **designated**; **Fallback B** (growth) is **rejected**.
  - Plain shipped halo remains **1.5 pt** warm-white (audit restore).
  - **Hold-Space** on a staged strip frame opens the loupe on the **ADAPTED** preview — this rule holds regardless of spike resolution.
- **why:** The 90 px question is whether adaptation is visible; proxy-linear + warm-in make change visible without inventing a chip (D43).
- **rejected:** Embedded-JPEG adapted lies; Fallback B growth; relying on halo alone without preview change; loupe that ignores staged adaptation.
- **history / socket:** R-Q.1 + audit “halo restored to 1.5 pt.” Supersedes `.cursorrules` “90 px halo (OPEN) / both fallbacks mocked and unpicked” — Fallback A is now designated (debug flag still acceptable as engineering socket). Touches D43, L2, WG-ripple, HiFiTokens.Ring.

### D59 — Same-mark clears *(audit)*

- **decision:** Pressing the **same mark key** on an already-marked frame **clears** that mark (P on kept clears keep; X on rejected clears reject). Adopted mechanic.
- **why:** Marks must be recoverable without a second verb; clearing is the natural toggle under L1 decision keys.
- **rejected:** Same-key no-ops; modal “unmark”; hover-to-clear.
- **history / socket:** Audit-accepted. **OPEN QUESTION:** audit required the mechanic “stated verbatim in the frozen copy,” but the constitution prompt did not paste the verbatim string — see OPEN QUESTIONS; do not invent the line.

### D60 — Return-release gate *(audit)*

- **decision:** A **Return-release gate** is adopted: Return/⏎ commit paths obey the release gate stated for this mechanic (no release-commit of staging; decision keys swallow repeat; ⇧⏎ then ⏎ are two presses). Exact gate wording belongs in the frozen copy per audit.
- **why:** Prevents timed-chord and release-commit banned patterns.
- **rejected:** Timed double-taps; release-commits; chord compression of ⇧⏎+⏎.
- **history / socket:** Audit-accepted. **OPEN QUESTION:** verbatim copy line not supplied in-session — see OPEN QUESTIONS.

### D61 — Export three-state *(audit)*

- **decision:** Export has exactly three visual states: **quiet text** (`Export —` when kept = 0) → **quiet outline** (kept > 0) → **dark primary** (cull-complete / Open receipts as specified). State-based primary rule (A2).
- **why:** Export must read as progress-of-decisions without progress bars.
- **rejected:** Progress bars; single always-dark Export; auto-jump into Export.
- **history / socket:** Audit-accepted; hi-fi frames 1–5. Touches D36, D44, copy OPEN/FINISHED strings.

### D62 — Post-commit focus advance *(audit)*

- **decision:** On commit (⏎) from a staged adapt/develop round, focus advances to the **next row’s first kept frame** (skips rejects). Plain arrows still walk every frame. Solo-edit ⏎ / decision-key advance to next kept remains as previously defined in working grammar.
- **why:** Edit phase reads row → row → row without auto-jump modes.
- **rejected:** Focus staying on the reference after commit as the only path; auto-skip that prevents re-marking rejects with arrows.
- **history / socket:** Audit-accepted; hi-fi staged/receipt notes. Touches WG-ripple, L1, D43.

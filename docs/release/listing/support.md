## Common questions

**Which files does it read?** Sony ARW files, in a folder you open or on a memory card.

**Where are my ratings?** Save writes a `.xmp` file next to each photo, with the same name. Other
photo apps that read XMP sidecars pick the ratings up from there.

**Why does it ask me to choose a folder?** Lumina is sandboxed: it can read only the folders you
pick. It remembers your choice, so reopening a shoot from the Open screen needs no panel.

**Why can't I save on the card?** Lumina never writes to a memory card. Copy the shoot to your Mac
first (Export), then save there.

**Where are my decisions kept?** In the app's own folder on your Mac. They stay when you quit and
are back when you reopen the same folder.

**Requirements:** a Mac with Apple silicon, macOS 15 or later.
